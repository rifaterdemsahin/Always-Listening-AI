How Grok Always-Listening works

Site version v1.6.0. This is a static page: your mic goes to xAI Grok over a WebSocket. Grok talks back. Pictures and Kokoro only run when you ask.

The loop

You say “Grok”     → wake word starts the session
You talk           → 24 kHz PCM to Grok (server VAD)
“draw me a car”    → picture in the transcript
“read it”          → Kokoro reads the last Grok reply
Anything else      → Grok answers out loud
Header timer       → stays online at least 3:00

1. Start — say “Grok”

While idle, Chrome Speech Recognition listens for the word Grok (this is not the xAI socket yet). Hearing it requests the microphone, opens wss://api.x.ai/v1/realtime?model=grok-voice-latest, and starts the 3:00 hold. You can also tap Start Listening. Paste an API key from console.x.ai first.

Browsers cannot set a WebSocket Authorization header. The page mints a client secret, then connects with xai-client-secret.<token>.

2. Talking — server-side VAD

After connect, session.update sets the Grok voice, server_vad (no push-to-talk), 24 kHz PCM, and tools. Mic frames go out as input_audio_buffer.append. When you pause, Grok replies. Audio deltas play through Web Audio. Talk over Grok to interrupt.

3. Pictures — “draw me a car”

Grok Voice often claims it has no canvas. If you ask to draw or show a picture, the page cancels that refusal and generates the image itself (xAI Imagine, or a fallback URL if GitHub Pages is blocked by CORS). Tap the picture to enlarge. Leave Images on.

4. Read aloud — wait for “read it”

Kokoro does not speak every reply. After Grok has answered, say read it (or “read it out loud”, “read that”). The page cancels Grok’s next turn and sends the last Grok bubble to:

POST https://secondbrain-kokoro.fly.dev/api/speak
Content-Type: application/json

{
  "text": "<last Grok reply>",
  "voice": "af_heart",
  "speed": 1
}

The green Kokoro API box shows that call. Copy curl copies it. Voices come from GET /voices. Keep Say “read it” on. You can still tap Read on a bubble or Read last.

5. Settings cookie

API key, voices, toggles, volume, and instructions are saved in the grok-voice-settings cookie (1 year) and in localStorage. The key is not sent to Kokoro.
