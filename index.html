Talk to Grok on this Deck

  1. Get an API key at console.x.ai and add credits.
  2. Open Settings and paste the key. It stays on this device.
  3. Use wired or Bluetooth headphones if you can — the Deck speakers will otherwise echo into the mic.
  4. Tap the big Start Listening button and allow the microphone prompt.
  5. Speak naturally. Server-side VAD detects when you start and stop. Interrupt Grok anytime.
  6. Ask Grok to show or generate a picture — it appears in the transcript. Tap it to enlarge.

Chrome / Chromium in SteamOS Desktop Mode works best. Open this page over http://localhost, not as a raw file:// URL.
